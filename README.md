# no-guess-minesweeper
一个无猜扫雷小游戏，所有局面均可通过逻辑推理完成，无运气成分，有四种难度档位选择
## 如何运行
直接用浏览器打开“index.html”即可开始游戏
##项目文件
-"indeex.html"：游戏界面与交互
-"game.js":游戏核心逻辑
-"测试程序"：游戏测试文件，用于测试各种情况下游戏的稳定性，验证无猜棋盘生成算法的可解性
##开发说明
本项目使用ai辅助编程完成。我负责拆解需求，设计测试，运行并验证结果。代码主体由ai生成，我在调试与修改过程中逐渐熟悉游戏逻辑与实现方式
##测试
测试程序对无猜棋盘算法进行了批量验证，确保每个棋盘都有唯一逻辑解
##项目局限
-功能较基础
-高难度棋盘生成有可感延迟
